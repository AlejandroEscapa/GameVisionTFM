## Dimension 01: Ecosistema Steam (oficial y estándar de facto)

*Investigado 2026-09-29 · 16 búsquedas web + verificación directa de endpoints en vivo (HTTP) + lectura íntegra de documentación oficial y primaria descargada. Las citas textuales marcadas como "verbatim" se reprodujeron de las fuentes listadas al final. Las cifras no verificadas se señalan explícitamente como "no encontrado".*

### Current State

- La **Steam Web API oficial** exige clave para todo uso: "All use of the Steam Web API requires the use of an API Key", obtenible gratis con la cuenta Steam; los endpoints estándar viven en `api.steampowered.com` y, para contenido "publisher", en `partner.steam-api.com`, donde "Every request to this host must be made with your publisher Web API key, even requests which would ordinarily not need any key" y los 403 (típico con clave normal) provocan límites estrictos por IP [^steamdev][^webapioverview].
- **Límite global de la API oficial**: "You are limited to one hundred thousand (100,000) calls to the Steam Web API per day." — por clave. No encontré en la Terms of Use vigente cifras adicionales ni un procedimiento oficial de ampliación (solo menciones comunitarias no verificadas) [^apiterms][^forum429].
- **Player Summaries** (`ISteamUser/GetPlayerSummaries/v2`): clave + hasta 100 SteamIDs por llamada; devuelve `personaname`, 3 tamaños de avatar, `profileurl`, `communityvisibilitystate`, `lastlogoff` [^iuser].
- **Biblioteca del usuario** (`IPlayerService/GetOwnedGames/v1`): clave + `steamid`; opciones `include_appinfo`, `include_played_free_games`, `appids_filter`; por juego devuelve `playtime_forever` y `playtime_2weeks` (minutos), iconos y `has_community_visible_stats`; "Returns a list of games owned by the player if their owned games/game details are visible to you" (es decir, biblioteca pública o visible) [^ipservice][^tf2wiki].
- **Recently Played** (`IPlayerService/GetRecentlyPlayedGames/v1`, con `count`), **playtime de una sola app** (`GetSingleGamePlaytime/v1`, restringido a la app de la clave), **nivel e insignias** (`GetSteamLevel/v1`, `GetBadges/v1`) [^ipservice].
- **Logros**: `ISteamUserStats/GetPlayerAchievements/v1` (clave + steamid + appid + idioma) para los logros del usuario; **`GetGlobalAchievementPercentagesForApp/v2` figura sin parámetro de clave → el porcentaje global por logro es consultable públicamente**; `GetSchemaForGame/v2` aporta nombres/iconos de logros y stats del juego; `GetUserStatsForGame/v2` las stats numéricas del usuario; `GetNumberOfCurrentPlayers/v1` el CCU actual (solo appid) [^iuserstats].
- **Noticias** (`ISteamNews/GetNewsForApp/v2`): sin clave listada; `count` por defecto 20; permite `maxlength`, `feeds`, fechas [^inews].
- **Steam Storefront API** (`store.steampowered.com/api/appdetails` y `/appreviews`): **no es API oficial documentada por Valve**; está documentada por la comunidad como "the unofficial and internal Steam Web API" [^revrepo]. Desde 2020 `appdetails` está "rate limited to 200 requests per 5 minutes" y con múltiples appids exige `filters=price_overview`; el dominio aplica además ~300 req/5 min [^revappdetails][^revhome]. Verificado en vivo (CS2, `cc=es`): precio por región, géneros, 19 categorías, 19 capturas, 4 vídeos (mp4/webm), `recommendations.total` = 5.289.554, plataformas e idiomas [^liveappdetails]. `appreviews` respondió en vivo con `query_summary` (`review_score_desc`: "Very Positive", totales positivo/negativo/reseñas) y reseñas con votos + `cursor`; la wiki comunitaria anota "No known rate limit" [^livereviews][^revreviews].
- **SteamSpy**: API pública, **gratis y sin clave**; datos refrescados 1 vez al día; "Allowed poll rate - 1 request per second for most requests, 1 request per 60 seconds for the all requests"; ofrece `owners` (rango), `average_forever`/`median_forever`, `ccu` (pico de ayer), precio/descuento, **`tags` de usuario con votos**, idiomas y género; requests: appdetails, genre, tag, top100…, all (1.000 por página) [^steamspy].
- **SteamDB: no tiene API** — su FAQ responde a "Does SteamDB have an API?" que quizá la haya "at some point"; su página /api/ declara directamente "SteamDB is a community website and does not have an API you can use" y remite a la API oficial. Su FAQ también confirma: "The Steam API only returns owned games for public profiles" [^steamdbfaq][^steamdbapi].
- **SteamGridDB v2**: clave gratuita personal (Bearer token); "SGDB uses an Authorization bearer token as authentication"; endpoints: `search/autocomplete/{term}`, `getGameBySteam`, y **grids/heroes/logos/icons** por juego o plataforma (+ upload/delete autenticado); grids de 920x430 o 460x215; **no documenta rate limit en su spec (no encontrado)** [^sgdb].
- **ProtonDB**: sin API oficial; existe **API comunitaria** open-source sobre volcados de datos (actualización ~cada 31 días; el deployment de demo usa "sample data") [^protondbapi]; el endpoint no oficial `protondb.com/api/v1/reports/summaries/{appid}.json` responde en vivo hoy: `{"tier":"gold","score":0.71,"confidence":"strong","total":2050}` (CS2) [^protondblive].
- **CheapShark**: GET público **sin clave** (verificado en vivo: devolvió ofertas con `steamAppID`, `steamRatingText`="Overwhelmingly Positive", `dealRating`…); su documentación está en apidocs.cheapshark.com; **no encontré rate limit ni ToS explícitos** de CheapShark en las fuentes consultadas [^cheapsharklive][^cheapsharkdocs].
- **IsThereAnyDeal**: clave por `key`/header `ITAD-API-Key` u **OAuth2 PKCE** para datos de usuario; **1.000 requests / 5 min** (con email verificado; 429 con `Retry-After`; piden caché explícitamente); **webhooks** de notificación disponibles; ToS: "You MAY use this API for commercial purposes IF the resulting app is available to public", obligación de enlace a ITAD, sin aparentar afiliación, sin competir con ITAD y sin modificar los datos [^itadyml][^itadtos].
- **Login Steam (OpenID)**: sigue documentado y vigente: "Steam is an OpenID Provider, as described in the OpenID 2.0 spec"; el OP endpoint es `https://steamcommunity.com/openid/` y permite obtener el SteamID sin que el usuario teclee credenciales (pedirlas "would be a violation of the API Terms of Use") [^auth][^steamdev].
- **Apps de referencia**: Augmented Steam (extensión oficial de IsThereAnyDeal sobre Steam: precios, resaltado de wishlist, filtros) [^augmented]; plugin Decky "SteamGridDB" (arte dentro de Gaming Mode) [^decky]; Home Assistant (integración que consume la Web API; el hilo #95702 ilustra el consumo: "36.000 API calls per day" frente al límite de 100k) [^ha]; Decky "EnhancedGV" (ficha de tienda dentro de Decky) [^enhancedgv].

### Oportunidades para GameVision

- **GetOwnedGames + RecentlyPlayedGames + playtime** → vista "Mi biblioteca Steam": importación completa, horas reales, "sigue jugando". **Adoptar ahora** — es la capa pro central; exige caché (TTL horas), tratar perfiles privados y decidir arquitectura de clave (clave de servidor compartida vs. patrón alternativo; ver Tensions). [^ipservice][^tf2wiki]
- **GetGlobalAchievementPercentagesForApp (+SchemaForGame)** → vista "Logros" con rareza global ("lo tiene el 3,1% de jugadores") — diferencial que RAWG no ofrece; **adoptar ahora** (público y barato). Añadir `GetPlayerAchievements` para el progreso personal: **después** (depende de visibilidad + sync). [^iuserstats]
- **GetPlayerSummaries** → cabecera "Mi perfil Steam" (avatar, alias, enlace). **Adoptar ahora**. [^iuser]
- **GetNumberOfCurrentPlayers** → contador "jugando ahora" en la ficha del juego. **Adoptar ahora** (llamada trivial). [^iuserstats]
- **GetNewsForApp** → pestaña "Novedades/Parches" por juego. **Después**. [^inews]
- **appdetails** → fichas pro: precio actual/rebajado en EUR y por región, capturas oficiales HD, categorías Steam (mando, cooperativo, logros, Workshop), vídeos, requisitos. Tapa huecos de RAWG (RAWG no da precios ni estas categorías). **Adoptar ahora** con caché agresiva (≤200 req/5 min) usando `filters` para lotes. [^revappdetails][^liveappdetails]
- **appreviews** → badge "Muy positivas · 5,2 M reseñas" y orden por valoración Steam. Complementa la duración de HLTB con la voz del jugador. **Adoptar ahora** (cache 24 h). [^revreviews][^livereviews]
- **SteamSpy** → tags de usuario (afinidad/recomendaciones), "tiempo medio jugado" (comparativa interesante con HLTB) y popularidad (owners). **Adoptar después** (refresco diario; cachear 24 h; son estimaciones). [^steamspy]
- **SteamGridDB** → calidad visual de la app: póster vertical, hero de cabecera, logo transparente, iconos; mejora inmediata de "carátulas". **Adoptar ahora** (clave gratuita; cachear; revisar términos del sitio antes de monetizar — no encontrados aquí). [^sgdb]
- **ProtonDB** → badge "Steam Deck/Linux: Gold" en ficha. **Después/opcional** — fuera del core Android, fuente no oficial; usar solo como adorno informativo con fallback. [^protondblive]
- **CheapShark** → sección "Ofertas" y "tu backlog está de rebajas"; base para alertas simples sin clave. **Adoptar ahora** para el MVP de ofertas. [^cheapsharklive]
- **IsThereAnyDeal** → capa premium de ofertas: sync de waitlist, histórico de mínimos y webhooks "objetivo de precio alcanzado". **Después** — condiciones compatibles con una app comercial pública si se atribuye y no se compite frontalmente. [^itadtos][^itadyml]
- **Steam OpenID** → "Sign in through Steam" para vincular cuenta en Android (Custom Tab + redirect de vuelta a la app). **Después** (fase 2); el MVP puede importar con la URL/vanity del perfil. [^auth][^steamdev]
- **SteamDB** → **descartar** como API (no existe; no scrapear); vale solo como referencia manual de investigación. Alternativas para sus datos históricos: las APIs anteriores (SteamSpy para estimaciones; ITAD para precios). [^steamdbapi][^steamdbfaq]

### Tensions & Counter-arguments

- **La cuota de 100k/día es por clave, no por usuario**: una app con miles de usuarios que replican llamadas puede agotarla. Home Assistant documenta consumos de decenas de miles de llamadas/día en un solo servicio [^ha]. Mitigación necesaria: caché, sincronización incremental y reparto horario. La opción "cada usuario aporta su clave" choca con la ToS ("You may not transfer, assign, or delegate the API Terms of Use and your Steam Web API key to any third party" y la exigencia de identificar la app en el registro) — decisión de arquitectura crítica y con riesgo legal si se hace mal. [^apiterms]
- **429 reales reportados en 2025 incluso con claves dentro del límite declarado** ("Steam Web API constantly rate-limited (Error 429) New key"); en el host partner los 403 escalan a "strict rate limits" por IP. El límite práctico puede ser más duro que el nominal. [^forum429][^webapioverview]
- **Los endpoints de store son no oficiales**: pueden cambiar sin aviso — el propio historial lo demuestra (el límite 200/5 min y el quirk de multi-appid se impusieron de golpe en 2020). Caching obligatorio y plan de contingencia si desaparecen. [^revappdetails]
- **"Overwhelmingly Positive" no es crítica profesional**: es una puntuación binaria de usuarios (`voted_up`), volátil y con sesgo de popularidad; no mezclar con escalas de RAWG/HLTB sin normalizar. [^livereviews]
- **SteamSpy son estimaciones**, no datos oficiales (owners en rango; muestreo; tags UGC; refresco diario). Presentables como "aprox." o "popularidad", nunca como cifra oficial. [^steamspy]
- **SteamDB**: intentar consumir sus endpoints es contra sus términos y su página lo bloquea activamente (mensaje explícito "does not have an API"). Descartado. [^steamdbapi]
- **SteamGridDB**: sin límites documentados visiblemente y con assets de comunidad → riesgo de disponibilidad y de derechos de imagen si se monetiza; revisar ToS del sitio y cachear en servidor propio. (Limitación de esta investigación: usé "as is", con licencias de assets **no verificadas**). [^sgdb]
- **ITAD**: cláusulas restrictivas — "You MUST NOT make an app that could be considered a competition to IsThereAnyDeal"; si GameVision evoluciona hacia comparador de precios puro, conflicto directo. Y "Attempts to work around the limits will cause ban". [^itadtos][^itadyml]
- **Privacidad de perfiles**: todo el pipeline de importación depende de perfiles públicos ("The Steam API only returns owned games for public profiles") → UX debe guiar (cómo poner el perfil público) y degradar con gracia. [^steamdbfaq]
- **OpenID 2.0 es un protocolo legado** (superado por OpenID Connect en la industria; Valve no ha anunciado migración, sigue documentado hoy). Planificar fallback de vinculación manual (SteamID/vanity) por si deprecan el endpoint. [^auth]
- **No encontrado / no verificado (declarado explícitamente)**: (1) límites oficiales de Valve para `appdetails`/`appreviews` (las cifras 200/5 min y 300/5 min provienen de documentación comunitaria, no de Valve); (2) rate limit de SteamGridDB; (3) rate limit y ToS explícitos de CheapShark; (4) requisito documental exacto de "perfil público" para logros (solo localicé la frase sobre juegos poseídos); (5) procedimiento oficial para ampliar el límite de 100k/día (solo comentarios de foro); (6) licencias de copyright de los assets de SteamGridDB para uso comercial.
