# Dimension 02: Consolas, trofeos y agregadores de datos

> Investigación para GameVision (app Android de tracking). Fecha de consulta: 2026-09-29. Los límites/precios citados corresponden a lo verificado en esa fecha (MobyGames vía Wayback, snapshot 2026-09-12). Se priorizó documentación oficial; donde no la hay, se documenta explícitamente.

### Current State

El ecosistema de datos de trofeos/logros se divide en tres capas bien diferenciadas:

**1. APIs de consola PSN/Xbox — oficialmente cerradas al público.**
- **PSN**: Sony tiene una API de trofeos pero no publica documentación; la referencia del sector es la doc comunitaria de andshrew, hecha "capturando las peticiones" de la web y "análisis de la app móvil" de PlayStation. En la práctica, los trackers funcionan con wrappers **no oficiales** que reutilizan los endpoints internos de Sony (auth vía NPSSO, el token de sesión web que "equivale a tu contraseña").
  - `psn-api` (npm, TypeScript, MIT, 424★, último push 2026-08-15): la opción más mantenida. Da títulos con trofeos, grupos (base/DLC), trofeos ganados por título, resumen por tipo (bronze/silver/gold/platinum), perfil de usuario, presencia, amigos, dispositivos, compras, **tiempo de juego** (`getUserPlayedGames`, "playtime info") y — clave para "Coleccionado" — **rareza** (`trophyRare`: UltraRare→Common) y **`trophyEarnedRate`: "Percentage of all users who have earned the trophy"** (% comunitario real, igual que en la app de PS).
  - `psnawp` (Python, ~198★; GitHub ahora es espejo read-only, desarrollo movido a Codeberg): dato de usuario, trofeos, juego y tienda. Advierte de forma explícita: uso excesivo "may lead to your PSN account being temporarily or permanently banned" y recomienda cuenta dedicada. Self-rate-limit de 300 req/15 min.
- **Xbox**: Microsoft solo ofrece logros de forma oficial vía **GDK/XSAPI para desarrolladores del propio título** (acceso restringido; las páginas GDK requieren autorización). Para terceros: `xbox-webapi-python` (OpenXbox, MIT, 208★, activo) para autenticar con Xbox Live y usar endpoints internos, y **OpenXBL (xbl.io)**, servicio de pago no oficial "turnkey" (perfiles, logros, amigos, clips, presencia, actividad en tiempo real) con capa gratuita y planes desde $5/mes. `xboxreplay` no fue verificable en esta ronda (servicio histórico; sin evidencia actual recogida).

**2. RetroAchievements — la excepción: API oficial, gratuita y completa.**
Logros retro multiplataforma con clave personal de cuenta. Además de logros/progreso/puntos, expone **distribución de desbloqueos por logro** (el % de jugadores que lo consiguió, como en la web), completados, awards/badges, rank y leaderboards. Es la fuente más limpia legalmente para alimentar "Coleccionado" con porcentajes comunitarios. Limitación: solo retro (no PS5/Xbox modernos).

**3. Agregadores de metadatos y crítica.**
- **IGDB (oficial)**: franquicias, compañías, géneros, plataformas, artworks/screenshots, `similar_games`, `game_time_to_beats` (hastily/normally/completely), `language_supports`, localizaciones, etc. Gratis para uso no comercial bajo el Twitch Developer Service Agreement; uso comercial por acuerdo ("commercial partnership"). Rate limit 4 req/s. No permite llamadas directas desde navegador (CORS).
- **RAWG**: la fuente actual de GameVision (oficial, key-based freemium). No re-verificada en esta ronda; se mantiene como referencia de comparación.
- **MobyGames (oficial, pago)**: base retro/profunda (créditos completos, grupos/series, covers, scores). Suscripción: Hobbyist $9.99/mo (solo no comercial), Bronze $99.99/mo (comercial), Silver $499.99/mo, Gold $4.999,99/mo; gratis solo para investigación no comercial.
- **OpenCritic**: API consumida por terceros vía wrappers no oficiales y vía RapidAPI; **no se encontraron docs públicas oficiales ni política de acceso publicada**.
- **Metacritic**: no se encontró API oficial pública; solo alternativas de scraping de terceros (no verificadas, zona gris legal).
- **Backloggd**: web de coleccionismo "Powered by IGDB"; sin API propia pública (es un consumidor, no una fuente).
- **GameFAQs / Glitchwave**: no se encontró API pública en esta ronda.
- **Apps de referencia**: TrueTrophies (título: "Playstation Trophy Tracking"; operada por TrueGaming Network Ltd, red de TrueAchievements — el modelo de negocio existe y escala) y apps más pequeñas que ya consumen OpenXBL para logros Xbox (SavePoint: "Xbox uses OpenXBL"; Acheev optimizó su sync "per OpenXBL call"). psn-api se usa en proyectos como PS5 MQTT.

### Oportunidades para GameVision

Por servicio: función que habilitaría + veredicto preliminar.

- **RetroAchievements → ADOPTAR AHORA.** Es la candidata fuerte para "Coleccionado": logros reales + **% comunitarios oficiales** (distribución de desbloqueos), puntos y completados, gratis, API oficial estable con key por usuario. Función: sync de logros retro + barras de progreso comunitarias; base del sistema de "colección de logros" multi-fuente (junto a Steam). Requisito de producto: pedir la web API key al usuario (fácil de obtener en su panel) y cachear agresivamente.
- **PSN vía psn-api/psnawp → DESPUÉS (piloto experimental controlado).** Habilitaría importar trofeos, horas de juego y rareza/% comunitario por trofeo — el corazón del tracking de consola. PERO: no oficial, NPSSO = credencial de sesión ("equivalente a tu contraseña"), riesgo real de baneo, violación de ToS de Sony. Si se hace: solo opt-in con consentimiento explícito, tratar el NPSSO como secreto extremo (ideal: no almacenarlo; usar tokens con backend propio, NUNCA en el dispositivo en claro), polling conservador, y evaluar "cuenta dedicada". `psn-api` (MIT, activo) es la mejor base técnica; alternativa futura: contacto con Sony para acceso legítimo (no existe programa público conocido).
- **Xbox vía OpenXBL → ADOPTAR AHORA (piloto), con abstracción.** Logros, gamerscore e historial con free tier (150 req/h según pricing oficial) suficiente para un usuario individual; escala con $5–35/mes por volumen. Ya hay precedentes de apps usándolo (SavePoint, Acheev). Diseñar una interfaz `AchievementProvider` para poder cambiar a otro proveedor si el servicio cambia límites o desaparece (ver disputa 150/h vs 150/día).
- **IGDB → PREPARAR MIGRACIÓN (después).** Migrar de RAWG a IGDB cuando se monetice o cuando se necesiten sus campos extra: franquicias, similares, time-to-beat, `language_supports` (idiomas), artworks. Gratis con OAuth (client credentials) en fase no comercial; 4 req/s manejable con caché; llamadas server-side (CORS bloquea navegador). Trabajo previo: capa de mapeo de IDs (RAWG↔IGDB↔PSN titleId↔Xbox titleId↔RA gameId) y doble fuente temporal. Nota: no pude confirmar desde la doc el listado de 50+ idiomas ni que "español" esté listado → verificar con la entidad `languages`/`language_supports` al integrar. La licencia comercial hay que negociarla (partner@igdb.com) — coste y tiempos desconocidos y no publicados.
- **MobyGames → DESCARTAR por ahora.** Datos excelentes (créditos retro) pero comercial desde $99.99/mo y cláusulas (crédito obligatorio, "cannot compete directly", no revender). No justificable pre-ingresos; reconsiderar si GameVision monetiza y el coleccionismo retro/profundo se vuelve prioritario; mientras, el formulario de acceso gratuito para investigación es la única vía económica.
- **OpenCritic → DESPUÉS (solo con permiso) / ahora DESCARTAR por riesgo.** La nota agregada ("Mighty"…) sería un diferenciador, pero no hay acceso documentado públicamente; usar wrappers/RapidAPI sin acuerdo es zona gris y frágil. Vía correcta: contactar a OpenCritic directamente y evaluar condiciones.
- **Metacritic → DESCARTAR.** Sin API oficial; scraping = riesgo ToS + fragilidad. Si se necesita nota de crítica, OpenCritic es la vía "más arreglable".
- **GameFAQs / Glitchwave → DESCARTAR como fuentes.** Sin API; no merece ingeniería inversa.
- **Backloggd → referencia de producto, no de datos.** Confirma que el motor de datos puede ser IGDB; útil como benchmark de UX de coleccionismo.
- **Apps de referencia → competencia y validación.** TrueTrophies/TrueAchievements (TrueGaming Network) prueban que hay demanda y modelo; GameVision puede diferenciarse con una "Colección" multi-fuente (PSN + Xbox + RetroAchievements + Steam) en una sola app Android, algo que los incumbentes hacen solo por plataforma o web.

### Tensions & Counter-arguments

- **Todo lo de PSN/Xbox de terceros es no oficial y con riesgo de cuenta.** psnawp lo dice sin rodeos ("temporarily or permanently banned") y sugiere cuenta dedicada; psn-api pide no abusar. La única vía 100% legítima es no usar estos endpoints → trade-off directo entre "feature estrella" y legalidad/ban-risk. Monetizar una app sobre APIs reverse-engineered aumenta la exposición legal. Decisión de producto: mantener tras un flag opt-in con advertencias, o posponer hasta tener contacto con los dueños de plataforma.
- **El "canal oficial" no existe para trackers.** En Xbox, la API oficial de logros (GDK) es para desarrolladores del propio juego y requiere autorización; no es una alternativa real para GameVision hoy. En PSN, no hay programa público de trofeos para terceros. Es decir: el competidor TrueTrophies también vive de acceso no oficial/no anunciado — el mercado entero está en esa zona.
- **Disputa de límites OpenXBL**: pricing oficial dice 150 req/hora; un proyecto comunitario afirma 150/día y que la etiqueta "requests/hour" es incorrecta. Implica: medir empíricamente antes de dimensionar features, implementar backoff 429 y no confiar en la UI del proveedor.
- **RetroAchievements**: gratis y oficial, pero (a) solo retro — no cubre PS5/Xbox Series, (b) política de "sé razonable" con rate limits no numéricos — exige caché y diseño de sync por lotes por usuario; el % comunitario es de su comunidad (sesgada a retro-hardcore), no del mercado general.
- **IGDB**: "free for non-commercial" — en cuanto GameVision monetece (ads, premium, donaciones "de facto"), hay que negociar partner program; condiciones y coste **desconocidos** (no publicados). Además CORS fuerza backend proxy y 4 req/s obliga a estrategia de caché; la afirmación "50+ idiomas" no pudo verificarse en la doc consultada.
- **MobyGames**: la cláusula "Cannot compete directly with MobyGames" es ambigua para una app de coleccionismo; el tier comercial mínimo ($99.99/mo) puede ser prohibitivo. Conflicto potencial entre sus términos y features de "colección/estadísticas" de GameVision → revisar con abogado si algún día se usa.
- **OpenCritic/Metacritic**: vacío de información verificado — no encontré términos oficiales de OpenCritic ni API de Metacritic. Cualquier plan debe partir de contacto directo con las empresas, no de wrappers; trátese como incógnita, no como disponible.
- **Privacidad (clave para Android)**: el NPSSO de PSN es equivalente a la contraseña; almacenarlo o transportarlo mal sería una vulnerabilidad crítica y un problema GDPR si no hay consentimiento informado. El diseño de seguridad (nunca persistir NPSSO en claro; tokens en backend cifrados; revocación fácil) es condición sine qua non para la feature PSN.
- **Mapeo de identidades**: cada fuente usa IDs propios (PSN `titleId`, Xbox `titleId`, RA `gameId`, IGDB `id`, RAWG `id`). Sin una capa de mapeo + almacén canónico, la "Colección" unificada se rompe. Coste de ingeniería subestimado frecuentemente; planificarlo antes de la migración a IGDB.
